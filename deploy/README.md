# Stock Portfolio Dashboard

A comprehensive, real-time stock portfolio management dashboard that provides investors with complete visibility into their investment performance across multiple asset classes.

## 🎯 Overview

The Stock Portfolio Dashboard is a modern, mobile-optimized web application designed to give investors a complete picture of their financial portfolio. It combines traditional stock holdings with RSU (Restricted Stock Units) tracking, providing real-time market data and comprehensive performance analytics.

## ✨ Key Features

### 📊 **Complete Portfolio Overview**
- **Total Wealth Tracking**: View your complete financial picture including both traditional portfolio holdings and RSU values
- **Real-time Market Data**: Live stock prices updated automatically every 5 minutes
- **Multi-currency Support**: Switch between USD and ILS (Israeli Shekel) with live exchange rates
- **Performance Metrics**: Track daily and total profit/loss across all investments

### 💼 **Portfolio Holdings Management**
- **Comprehensive Stock Tracking**: Monitor 15+ individual stock positions with detailed metrics
- **Advanced Table View**: Sortable, customizable table showing all key performance indicators
- **Allocation Analysis**: See how each holding contributes to your overall portfolio
- **Cost Basis Tracking**: Monitor average cost per share and total investment amounts

### 🏢 **RSU (Restricted Stock Units) Tracking**
- **Dedicated RSU Section**: Separate tracking for company stock awards
- **Base Price Monitoring**: Track performance against grant prices
- **Multi-API Support**: Reliable price data from multiple financial data providers
- **International Stock Support**: Handle both US and Canadian stocks with automatic currency conversion

### 📱 **Mobile-First Design**
- **Responsive Interface**: Optimized for all screen sizes from mobile to desktop
- **Touch-Friendly Controls**: Easy navigation and interaction on mobile devices
- **Sticky Headers**: Important information always visible while scrolling
- **Collapsible Sections**: Organize information with expandable/collapsible cards

### 🔧 **Customization & Control**
- **Column Management**: Show/hide and reorder table columns to match your preferences
- **Persistent Settings**: All preferences saved locally for consistent experience
- **Sortable Data**: Click any column header to sort by that metric
- **Collapsible Cards**: Organize your dashboard by collapsing sections you don't need

### 🔄 **Real-Time Updates**
- **Auto-Refresh**: Data updates automatically every 5 minutes
- **Manual Refresh**: Force refresh data with a single click
- **Offline Support**: Cached data available when internet connection is unavailable
- **Error Handling**: Graceful fallback to cached data when live updates fail

### 💰 **Financial Analytics**
- **Daily P&L Tracking**: See how much you gained or lost today
- **Total P&L Analysis**: Track overall performance since purchase
- **Percentage Returns**: Both daily and total return percentages
- **Portfolio Allocation**: Understand how your money is distributed across holdings

### 🌍 **Multi-Currency Support**
- **USD/ILS Toggle**: Switch between US Dollar and Israeli Shekel
- **Live Exchange Rates**: Real-time currency conversion using Frankfurter API
- **Consistent Display**: All values update automatically when switching currencies
- **Local Storage**: Currency preference remembered across sessions

### 🎨 **Modern User Interface**
- **Dark Theme**: Easy on the eyes with professional dark color scheme
- **Gradient Accents**: Beautiful visual elements that highlight important information
- **Color-Coded Performance**: Green for gains, red for losses, intuitive visual feedback
- **Smooth Animations**: Polished interactions and transitions throughout

### 🔍 **Debug & Monitoring**
- **Debug Console**: Built-in debugging tools for troubleshooting
- **Log Management**: View and export system logs for analysis
- **Performance Monitoring**: Track data loading and API performance
- **Error Reporting**: Clear error messages and fallback mechanisms

## 🚀 **Getting Started**

1. **Open the Dashboard**: Simply open `index.html` in any modern web browser
2. **View Your Portfolio**: Your holdings will load automatically with real-time data
3. **Customize Your View**: Use the column controls to show/hide information you care about
4. **Switch Currencies**: Use the currency toggle to view values in your preferred currency
5. **Monitor Performance**: Check back regularly to see how your investments are performing
